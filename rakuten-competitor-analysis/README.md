# 乐天竞品分析工具

适用品类：桌子、宠物笼子、宠物厕所、航空箱（品类和关键词可以在 `config.yaml` 里随便改）。
我的店铺：`sanc66666`、`happy8888`。

## 能分析什么

| 模块 | 内容 |
|---|---|
| 我的商品诊断 | 每个商品的最好搜索排名、价格在市场里的位置、评价/积分/包邮和前30名对比，自动给出改进建议（降价、包邮、加积分、标题缺哪些热词…） |
| 关键词排名 | 每个关键词下我排第几、第1名是谁、前10名的均价/评价/包邮率 |
| 价格带分析 | 各价格带的商品占比（供给）和评价占比（需求），找出「需求大、竞争少」的机会价格带 |
| 竞争店铺排行 | 哪些店铺占据前30名、评价总数、平均价格、包邮率、积分倍率 |
| 爆款 TOP20 | 评价最多的商品（评价数 ≈ 累计销量） |
| 标题热词 | 排名靠前的商品标题里常用、而我的标题里没有的词 |
| 趋势变化 | 和上一次运行比：竞品评价增长（换算成估算月销量）、改价、排名升降。**建议每天或每周固定跑一次** |

结果输出到 `output/`：一个 Excel（每个模块一张表 + 原始数据）和一个网页报告（会自动打开）。

## 使用步骤

1. 安装 Python 3.10 以上（Windows 安装时勾选 “Add Python to PATH”）
2. 申请乐天 API Key（免费）：
   - 打开 https://webservice.rakuten.co.jp/ ，用乐天账号登录 → 「アプリID発行」/ 新規アプリ登録
   - 「WebサイトURL」可以填你的店铺网址，例如 `https://www.rakuten.co.jp/sanc66666/`
   - 拿到 **アプリID（applicationId）** 和 **アクセスキー（accessKey）**
3. 打开 `config.yaml`，填 `application_id`、`access_key`，`site_url` 填上一步登记的网址
4. 运行：
   - Windows：双击 `运行.bat`
   - 或命令行：`pip install -r requirements.txt` 然后 `python main.py`

想先看看效果：`python main.py --demo`（模拟数据，不需要 API Key）。

## 调整

- **关键词**：`categories` 里每个品类的 `keywords`，用买家在乐天搜索框里输入的日语词
- **排除词**：`exclude`，过滤配件、替换零件等
- **价格带**：`price_bins`
- **类目 ID**：`genre_id` 填乐天类目 ID 后搜索更精准，并会额外抓类目排行榜
- **盯防对手**：先跑一次，在「竞争店铺」里找到对手的店铺代码，填进 `watch_shops`
- **销量估算**：`review_rate` = 大约多少比例的订单会留评价（默认 3%）。估算销量只是参考，看相对大小更有意义

## 说明

- 用的是乐天官方 Web Service API（2026 年新版，`openapi.rakuten.co.jp`），不爬网页，不会被封店。乐天限制约 1 次/秒，默认配置一次完整运行约需 3~5 分钟
- 同一天重复运行会用 `cache/` 里的缓存，不会重复请求
- 历史数据保存在 `output/history.db`，不要删，趋势分析靠它
- API 不提供真实销量和流量，所以销量是根据评价增长估算的；店铺后台（RMS）的数据需要你自己导出
- 乐天如果再改 API 地址，只需改 `config.yaml` 里的 `search_endpoint` / `ranking_endpoint`
