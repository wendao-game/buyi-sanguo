# 烽火守城 · 三国塔防（H5 原型 v0.1）

竖屏 9:16 的三国题材守城塔防 + 抽卡养成。纯 HTML5 Canvas，无引擎、无图片素材（武将/敌人/战场全部程序绘制），不依赖网络。

## 怎么运行

- 直接双击 `index.html` 用浏览器打开即可。
- 或本地服务器（Windows，不需要 Node/Python）：
  ```
  powershell -ExecutionPolicy Bypass -File serve.ps1
  ```
  然后打开 http://localhost:8731 ，浏览器开发者工具切到手机竖屏尺寸看效果。

## 玩法循环

出征守城 → 掉落/结算金币 → 金币换招募令（或每日看广告领）→ 招募武将 → 升级 / 升星 / 布阵 → 打更高关卡

| 模块 | 内容 |
|---|---|
| 战斗 | 每关 10 波，最后一波出敌将；5 个站位；武将自动普攻，怒气满后放大招（可自动 / 手动）；每 3 波一次“军令三选一”；×1/×2/×3 倍速 |
| 攻击类型（7） | 弓（单体高频）、刃（贯穿刀气）、火（范围+灼烧）、冰（范围+减速）、雷（弹跳闪电）、毒（毒潭）、风（旋风击退） |
| 品质 | 白 绿 蓝 紫 金 橙 已开放，共 32 名武将；黑、彩为神将，图鉴里占位显示，暂不可抽 |
| 招募 | 单抽 / 十连（必出紫以上）；60 抽保底橙；重复武将转碎片用于升星 |
| 经济 | 对局金币：通关奖励 + 战场掉落；100 金币 = 1 招募令；每日 5 次广告，每次 1 张招募令；首通每关送 1 张（章末关 5 张） |
| 养成 | 金币升级（每级 +8%）、碎片升星（每星 +20%，最高 5 星） |
| 存档 | 浏览器 localStorage，主城页可重置 |

## 文件结构

```
sanguo-td/
  index.html
  css/style.css   界面样式（#app 固定 540×960，整体缩放适配）
  js/data.js      所有数值：经济、概率、品质、武将、敌人、波次、军令（调平衡只改这里）
  js/save.js      存档、武将数值、布阵、金币兑换、广告次数、抽卡、结算
  js/assets.js    图片素材加载（assets/ 里有图就替换程序绘制）
  js/art.js       程序化绘制：战场、武将、敌人、头像
  js/battle.js    战斗引擎：波次、普攻/大招、特效、绘制
  js/ui.js        主城 / 武将 / 招募 / 战斗 HUD / 弹窗
  js/main.js      启动、屏幕适配、主循环
  serve.ps1       本地静态服务器
  assets/         美术素材：bg/ heroes/ enemies/（规格见 美术素材规格.md）
  tools/art-guide.html  美术模板页：下载带标注的背景参考图、武将/敌人模板
```

## 常用调节项（js/data.js 的 CFG）

- `TICKET_PRICE` 金币兑换价、`AD_DAILY_LIMIT` 每日广告次数、`AD_REWARD` 每次广告奖励
- `QUALITIES[].rate` 各品质概率、`PITY` 保底抽数、`TEN_GUARANTEE_Q` 十连保底品质
- `ENEMY_HP_SCALE` 整体难度、`WAVES` 每关波数、`COIN_DROP_RATE` 掉钱概率

## 广告接入

`js/save.js` 里的 `AdService.showRewarded()`：检测到 TapTap 小游戏（`tap.createRewardedVideoAd`）或抖音小游戏（`tt.…`）环境会走平台真实激励视频，
把 `AD_UNIT_ID` 换成自己的广告位即可；普通网页里是 5 秒倒计时的模拟广告。发奖逻辑在 `adGrant()`，与广告实现无关。

## 调试参数

网址后加：`?coins=5000&tickets=50&stage=12&all=1`（金币 / 招募令 / 解锁到第几关 / 获得全部已开放武将）

## 还没做的

- 黑、彩神将（数据里已预留 `locked: true` 的四名，去掉标记并给 `rate` 即可进卡池）
- 音效、新手引导、武将专属技能（目前大招按攻击类型区分）
- 移植到抖音/微信小游戏：界面是 DOM 写的，需要改成 Canvas 界面或换 Cocos/Laya
- 数值只做了第一版粗调，推荐战力是按模拟对局估的

## 换美术素材

把图片按约定文件名放进 `assets/`，刷新即替换，没放的继续用程序画的：

- `assets/bg/battle.png`（1080×1920）战场背景
- `assets/heroes/<武将id>.png`（512×512 透明底，脚底中心在 256,440）武将立绘；`<武将id>_head.png` 头像可选
- `assets/enemies/<敌人id>.png`（同上）敌人

完整规格和武将 id 对照见 `美术素材规格.md`；模板在 http://localhost:8731/tools/art-guide.html 下载。
技能特效和界面图标目前仍是程序画的。
