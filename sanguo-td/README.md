# 烽火守城 · 三国塔防（H5 v0.9）

竖屏 9:16 的三国题材守城塔防 + 抽卡养成。HTML5 游戏：战斗画面用 WebGL（PixiJS）渲染、不支持时自动退回 Canvas 2D，界面是网页 DOM；所有文件都在本地，不依赖网络。

## 怎么运行

- 直接双击 `index.html` 用浏览器打开即可。
- 或本地服务器（Windows，不需要 Node/Python）：
  ```
  powershell -ExecutionPolicy Bypass -File serve.ps1
  ```
  然后打开 http://localhost:8731 ，浏览器开发者工具切到手机竖屏尺寸看效果。

## 玩法循环

出征守城 → 掉落/结算金币 → 金币换招募令（或每日看广告领）→ 招募武将 → 升级 / 升星 / 凑羁绊 / 排站位 → 打更高关卡；已通关的关卡每天可以扫荡

| 模块 | 内容 |
|---|---|
| 战斗 | 每关 10 波，最后一波出敌将；5 个站位；武将自动普攻，怒气满后放专属大招（自动 / 手动）；每 3 波一次“军令三选一”；×1/×2/×3 倍速 |
| 局内操作 | **投石**：点战场任意位置投下礌石（最多存 3 块，6 秒回一块），伤害跟着关卡走，专打扎堆的小兵；**瞄准大招**：关掉「自动」后，点带「可瞄准」的大招头像进入慢动作，再点战场选落点（再点一次头像 = 自动选目标） |
| 专属技能 | 32 名武将各有一个**专属被动**和一个**专属大招**（见 `js/skills.js`），3 星**觉醒**：大招效果 ×1.5 |
| 站位 | 左右翼：弓、火、毒、雷系出手速度 +15%；两个前锋位：刃、风、冰系攻击 +15%；中间主帅：全军攻击 +品质×3%，本人怒气 +20% |
| 阵营羁绊 | 魏（出手速度）蜀（攻击）吴（怒气）群（暴击），同阵营 2 / 3 / 4 人逐级加成 |
| 缘分 | 16 组：五虎上将、关氏父子、赤壁之盟、江东双璧、魏之谋主、黄巾起义、蜀汉旧将（初始武将就能凑）…… |
| 攻击类型（7） | 弓、刃、火、冰、雷、毒、风，决定普攻形态 |
| 品质 | 白 绿 蓝 紫 金 橙 已开放，共 32 名武将；黑、彩为神将，图鉴里占位显示，暂不可抽 |
| 招募 | 单抽 / 十连（必出紫以上）；60 抽保底橙；重复武将转碎片用于升星 |
| 经济 | 对局金币：通关奖励（重复通关减半）+ 战场掉落；200 金币 = 1 招募令；每日 5 次广告，每次 1 张招募令；首通每关送 1 张（章末关 5 张）；扫荡每日 5 次；武将等级可以重置，**全额返还金币** |
| 数值 | 战力预算表 → 敌人强度、推荐战力 → 模拟器校准，全套说明见 **《数值规划.md》** |
| 战斗界面 | 顶部关卡标题、绿色波次条、红色城防条；左侧一列：暂停（带计时）、战斗统计、倍速、自动、投石、换将；右侧一列：5 名武将的大招按钮；底部城楼不放按钮 |
| 局中换将 | 战斗中点左侧「阵」（或暂停菜单里的「更换武将」）随时换人、换站位：留在场上的武将怒气保留；新上场的怒气从 0 开始、1.5 秒后出手；已选的军令照常生效，城防按比例折算 |
| 暂停菜单 | 继续战斗 / 更换武将 / 重新开始 / 返回主城 |
| 结算 | 显示每名武将的伤害和占比，方便调整阵容 |
| 存档 | 浏览器 localStorage；TapTap 里另有**云存档**和**本机文件备份**；所有平台都可以导出 / 读入**存档码**（主城「设置 · 存档」） |

## 战斗画面：WebGL（PixiJS）+ 2D 兼容

- 战斗画面默认用 WebGL 渲染（`js/glview.js`，引擎是 PixiJS 7.4.2，放在 `js/lib/pixi.min.js`，本地文件、MIT 许可）。
  它只负责画：读 `battle.js` 的战斗状态，把背景、敌人、武将、技能、界面文字都用显卡画出来。
- 比 2D 多的效果：动态光照（场景压暗，灯笼、火焰、技能照亮周围）、发光特效的泛光、敌将阵亡和大招的冲击波扭曲、更多火星；贴图自动合批，敌人和粒子多了不卡。
- 自动退回：浏览器不支持 WebGL、绘制出错、显卡上下文丢失时，自动改用 `battle.js` 里原来的 Canvas 2D 画法，游戏照常能玩。
  帧率持续低于约 38 帧时，依次关掉泛光、光照。
- 手动切换：主城「设置 · 存档」→「战斗画面：高清（WebGL）/ 兼容（2D）」。
- 界面（主城、武将、招募、弹窗）仍是网页 DOM。要上微信 / 抖音小游戏还得把界面也搬进 PixiJS 或换引擎。
- 改画面时两边都要顾到：新特效先在 `glview.js` 里做，2D 那份保持能看就行。

## 音效、新手提示、加载

- **音效**（`js/sfx.js`）：全部用 Web Audio 现场合成，没有音频文件。出手（7 种攻击类型各一种）、大招（锣声）、爆炸、落雷、投石、铜钱、城墙受击、每波三声战鼓、敌将登场号角、胜负、抽卡、升级、按钮。
  同一个音效有最短间隔、同时发声有上限。主城「设置 · 存档」里可以关。还没有背景音乐。
  以后想换成录好的音效，只改 `Sfx.play()` 里按名字播放文件即可，调用处不用动。
- **新手提示**（`ui.js` 的 `tip()`）：每条只出现一次，记在存档的 `tips` 里。现有：先去招募、扫荡、站位和主帅、羁绊、投石、大招和瞄准。
- **加载**：人物和敌人图存成 256 色调色板 PNG（`slice_sheets.py` 的 `save_png`），全部图片约 3.4MB（压缩前 11MB）；启动时有加载进度条，12 秒还没加载完就先进游戏。

## 字体（本地打包，不走外网）

- 三款开源字体，按游戏里实际用到的字裁小后放在 `assets/fonts/`（共约 270KB），用 css 的 `@font-face` 本地加载，不依赖谷歌字体或任何外网：
  - `round.woff2` 站酷快乐体：按钮、标题、武将名
  - `brush.woff2` 马善政毛笔体：logo、大标题、大招名（只留用得到的约 370 个字）
  - `num.woff2` Fredoka：数字和英文字母
- 都是 SIL Open Font License 1.1，可商用、可随游戏分发；许可全文在 `assets/fonts/*.OFL.txt`，原始字体在 `tools/fonts-src/`。
- **改了游戏里的文字（新武将名、新技能名等）之后**，在仓库根目录运行一次 `python3 sanguo-td/tools/build_fonts.py`（需要 `pip install fonttools brotli`）重新裁字；没运行也不会出错，新出现的字会退回系统字体。
- 小号说明文字保持系统字体（好认）。

## 常用调节项（js/data.js 的 CFG）

先看《数值规划.md》。常改的几项：

- `TICKET_PRICE` 金币兑换价、`LEVEL_COST` / `LEVEL_COST_POW` 升级花费、`LEVEL_REFUND` 重置等级返还比例、`REPLAY_COIN` 重复通关金币比例
- `AD_DAILY_LIMIT` 每日广告次数、`AD_REWARD` 每次广告奖励
- `QUALITIES[].rate` 各品质概率、`PITY` 保底抽数、`TEN_GUARANTEE_Q` 十连保底品质
- `ENEMY_HP_SCALE` 整体难度、`WAVES` 每关波数、`COIN_DROP_RATE` 掉钱概率
- `ROCK_MAX` / `ROCK_CD` / `ROCK_DMG` 投石、`AIM_SLOW` 瞄准慢动作、`AWAKEN_STAR` 觉醒星级、`SWAP_DELAY` 局中换将后多久出手
- `CC_DECAY` / `CC_MIN` / `PUSH_DECAY` / `PUSH_MIN` 敌人的控制抗性（被控次数越多，控制越短）
- `SWEEP_DAILY` / `SWEEP_MUL` 扫荡
- `SLOT_ROLES` 站位、`FACTION_BONDS` 阵营羁绊、`COMBOS` 缘分
- `STAGE_POWER` 每章战力预算（= 推荐战力）、`HP_PER_POWER` 敌人血量系数：模拟器校准出来的，战力到推荐值时挂机约三局赢两局；改法见《数值规划.md》第 7 节

## 发布前要做的

1. **广告位**：把后台申请的激励视频广告位 ID 填进 `js/data.js` 的 `CFG.AD_UNIT_ID`。留空时，在 TapTap / 抖音里不显示广告入口（网页版仍是 5 秒模拟广告）。
   点了广告 `CFG.AD_WAIT` 秒（默认 20）还没播出来就当这次没有广告，不会卡住。
2. **调试参数**：`?coins=5000&tickets=50&stage=12&all=1` 只在本机（`file://`、`localhost`、`127.0.0.1`）生效；正式网址和小游戏里一律忽略。
3. **云存档**：在 TapTap 开发者后台开通云存档。存档名是 `CFG.CLOUD_NAME`；进游戏时下载云端那份，与本机比较“累计获得金币”（`earned`，只增不减），取更多的那份；之后有变化、不在战斗中时最多每 `CFG.CLOUD_EVERY` 秒上传一次。
4. **美术图**：放了新图要更新 `assets/manifest.js`（用 `serve.ps1` 启动一次会自动重写）。
5. **礼包码**：`js/data.js` 的 `CFG.GIFT_CODES` 里现在有一个试玩用的码 `FENGHUO100`（招募令 100、金币 5000，每份存档只能用一次），上线前删掉或换成活动用的码。

## 广告接入

`js/platform.js` 里的 `AdService.showRewarded()`：检测到 TapTap 小游戏（`tap.createRewardedVideoAd`）或抖音小游戏（`tt.…`）环境会走平台真实激励视频；
普通网页里是 5 秒倒计时的模拟广告。发奖逻辑在 `save.js` 的 `adGrant()`，与广告实现无关。

## 还没做的

- 黑、彩神将（数据里已预留 `locked: true` 的四名，去掉标记并给 `rate` 即可进卡池；它们暂时用攻击类型的通用大招，正式开放前在 `skills.js` 补专属技能）
- TapTap 换账号：云存档按账号区分，但本机存储不分账号；同一台设备换 TapTap 账号时，进游戏会取两份里“累计获得”更多的那份（布衣三国里有按存档编号分账号的做法，可以移植）
- 移植到抖音/微信小游戏：界面是 DOM 写的，TapTap 小游戏可以直接用；抖音/微信需要改成 Canvas 界面或换 Cocos/Laya

## 美术现状（v0.4）

- **烽火守城走自己的画风，不用布衣三国的素材**：国风 Q 版卡通（粗黑描边、平涂加简单阴影、颜色鲜艳），高俯视角、武将背身守城，脚下深色圆形底座。
- **美术已全部画完**：32 名武将和 4 名未开放神将的战场立绘、正面头像；全部敌人（黄巾兵 / 官军两套敌兵、9 位各章敌将）；战场背景；全部技能特效（特效 1～3）。代码画的占位小人只在图片缺失时兜底；技能特效贴图在 `assets/fx/`（叠加混合发光）；缺图时由 `js/fxgen.js` 用代码生成同名贴图顶上。
- 2.5D：敌人远小近大、远处烟尘罩层、左上暖光、暗角调色、地面颗粒；有立绘图片时自动加斜投影。
- **出图**：提示词在 `tools/art-prompts-25d.html`（武将 4 张九宫格、头像 4 张、敌人 2 张、战场背景 1 张、技能特效 3 张）。
  画好后放进 `assets/_sheets/`（hero_1.png … hero_4.png、head_1.png … head_4.png、enemy_1.png、enemy_2.png、battle.png、fx_1.png … fx_3.png），在仓库根目录运行：
  ```
  python3 sanguo-td/tools/slice_sheets.py
  ```
  它会切开九宫格、抠底、对齐脚底、缩放，放进 heroes/ enemies/ fx/ bg/，并重写 assets/manifest.js。有图片的用图片，没有的继续用代码画的。

## 换美术素材

把图片按约定文件名放进 `assets/`，并登记到 `assets/manifest.js`（`serve.ps1` 启动时自动生成），刷新即替换，没放的继续用程序画的：

- `assets/bg/battle.png`（1080×1920）战场背景
- `assets/heroes/<武将id>.png`（512×512 透明底，脚底中心在 256,440）武将立绘；`<武将id>_head.png` 头像可选
- `assets/enemies/<敌人id>.png`（同上）敌人

完整规格和武将 id 对照见 `美术素材规格.md`；模板在 http://localhost:8731/tools/art-guide.html 下载。
技能特效和界面图标目前仍是程序画的。
