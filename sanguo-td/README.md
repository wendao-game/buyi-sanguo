# 烽火守城 · 三国塔防（H5 v0.2）

竖屏 9:16 的三国题材守城塔防 + 抽卡养成。纯 HTML5 Canvas，无引擎、无图片素材（武将/敌人/战场全部程序绘制），不依赖网络。

## 怎么运行

- 直接双击 `index.html` 用浏览器打开即可。
- 或本地服务器（Windows，不需要 Node/Python）：
  ```
  powershell -ExecutionPolicy Bypass -File serve.ps1
  ```
  然后打开 http://localhost:8731 ，浏览器开发者工具切到手机竖屏尺寸看效果。

## 玩法循环

出征守城 → 掉落/结算金币 → 金币换招募令（或每日看广告领）→ 招募武将 → 升级 / 升星 / 凑羁绊 / 排站位 → 打更高关卡；已通关的关卡每天可以扫荡

| 模块 | 内容 |
|---|---|
| 战斗 | 每关 10 波，最后一波出敌将；5 个站位；武将自动普攻，怒气满后放专属大招（自动 / 手动）；每 3 波一次“军令三选一”；×1/×2/×3 倍速 |
| 局内操作 | **投石**：点战场任意位置投下礌石（最多存 3 块，6 秒回一块），伤害跟着关卡走，专打扎堆的小兵；**瞄准大招**：关掉「自动」后，点带「可瞄准」的大招头像进入慢动作，再点战场选落点（再点一次头像 = 自动选目标） |
| 专属技能 | 32 名武将各有一个**专属被动**和一个**专属大招**（见 `js/skills.js`），3 星**觉醒**：大招效果 ×1.5 |
| 站位 | 左右翼：弓、火、毒、雷系出手速度 +15%；两个前锋位：刃、风、冰系攻击 +15%；中间主帅：全军攻击 +品质×3%，本人怒气 +20% |
| 阵营羁绊 | 魏（出手速度）蜀（攻击）吴（怒气）群（暴击），同阵营 2 / 3 / 4 人逐级加成 |
| 缘分 | 16 组：五虎上将、关氏父子、赤壁之盟、江东双璧、魏之谋主、黄巾起义、蜀汉旧将（初始武将就能凑）…… |
| 攻击类型（7） | 弓、刃、火、冰、雷、毒、风，决定普攻形态 |
| 品质 | 白 绿 蓝 紫 金 橙 已开放，共 32 名武将；黑、彩为神将，图鉴里占位显示，暂不可抽 |
| 招募 | 单抽 / 十连（必出紫以上）；60 抽保底橙；重复武将转碎片用于升星 |
| 经济 | 对局金币：通关奖励 + 战场掉落；100 金币 = 1 招募令；每日 5 次广告，每次 1 张招募令；首通每关送 1 张（章末关 5 张）；扫荡每日 5 次 |
| 结算 | 显示每名武将的伤害和占比，方便调整阵容 |
| 存档 | 浏览器 localStorage；TapTap 里另有**云存档**和**本机文件备份**；所有平台都可以导出 / 读入**存档码**（主城「设置 · 存档」） |

## 文件结构

```
sanguo-td/
  index.html
  css/style.css    界面样式（#app 固定 540×960，整体缩放适配）
  js/data.js       所有数值：经济、概率、品质、武将、敌人、波次、站位、羁绊、缘分、军令（调平衡改这里）
  js/skills.js     32 名武将的专属被动和专属大招
  js/save.js       存档、武将数值、阵容加成与战力、布阵、金币兑换、广告次数、扫荡、抽卡、结算、存档码
  js/platform.js   平台接口：激励视频（含超时）、TapTap 云存档、本机文件备份
  js/assets.js     图片素材加载（只加载 assets/manifest.js 里登记的图）
  js/art.js        程序化绘制：战场、武将、敌人、头像
  js/battle.js     战斗引擎：波次、普攻/大招、敌人状态、投石、瞄准、特效、绘制
  js/ui.js         主城 / 武将 / 招募 / 战斗 HUD / 弹窗
  js/main.js       启动、屏幕适配、主循环
  serve.ps1        本地静态服务器（启动时自动重写 assets/manifest.js）
  assets/          美术素材：bg/ heroes/ enemies/（规格见 美术素材规格.md）
  tools/art-guide.html  美术模板页
```

## 常用调节项（js/data.js 的 CFG）

- `TICKET_PRICE` 金币兑换价、`AD_DAILY_LIMIT` 每日广告次数、`AD_REWARD` 每次广告奖励
- `QUALITIES[].rate` 各品质概率、`PITY` 保底抽数、`TEN_GUARANTEE_Q` 十连保底品质
- `ENEMY_HP_SCALE` 整体难度、`WAVES` 每关波数、`COIN_DROP_RATE` 掉钱概率
- `ROCK_MAX` / `ROCK_CD` / `ROCK_DMG` 投石、`AIM_SLOW` 瞄准慢动作、`AWAKEN_STAR` 觉醒星级
- `SWEEP_DAILY` / `SWEEP_MUL` 扫荡
- `SLOT_ROLES` 站位、`FACTION_BONDS` 阵营羁绊、`COMBOS` 缘分
- `stageRecommend()` 推荐战力：按自动战斗模拟校准，达到推荐战力大约五成以上胜率，章末决战另加 15%

## 发布前要做的

1. **广告位**：把后台申请的激励视频广告位 ID 填进 `js/data.js` 的 `CFG.AD_UNIT_ID`。留空时，在 TapTap / 抖音里不显示广告入口（网页版仍是 5 秒模拟广告）。
   点了广告 `CFG.AD_WAIT` 秒（默认 20）还没播出来就当这次没有广告，不会卡住。
2. **调试参数**：`?coins=5000&tickets=50&stage=12&all=1` 只在本机（`file://`、`localhost`、`127.0.0.1`）生效；正式网址和小游戏里一律忽略。
3. **云存档**：在 TapTap 开发者后台开通云存档。存档名是 `CFG.CLOUD_NAME`；进游戏时下载云端那份，与本机比较“累计获得金币”（`earned`，只增不减），取更多的那份；之后有变化、不在战斗中时最多每 `CFG.CLOUD_EVERY` 秒上传一次。
4. **美术图**：放了新图要更新 `assets/manifest.js`（用 `serve.ps1` 启动一次会自动重写）。

## 广告接入

`js/platform.js` 里的 `AdService.showRewarded()`：检测到 TapTap 小游戏（`tap.createRewardedVideoAd`）或抖音小游戏（`tt.…`）环境会走平台真实激励视频；
普通网页里是 5 秒倒计时的模拟广告。发奖逻辑在 `save.js` 的 `adGrant()`，与广告实现无关。

## 还没做的

- 黑、彩神将（数据里已预留 `locked: true` 的四名，去掉标记并给 `rate` 即可进卡池；它们暂时用攻击类型的通用大招，正式开放前在 `skills.js` 补专属技能）
- 音效、新手引导
- TapTap 换账号：云存档按账号区分，但本机存储不分账号；同一台设备换 TapTap 账号时，进游戏会取两份里“累计获得”更多的那份（布衣三国里有按存档编号分账号的做法，可以移植）
- 移植到抖音/微信小游戏：界面是 DOM 写的，TapTap 小游戏可以直接用；抖音/微信需要改成 Canvas 界面或换 Cocos/Laya

## 换美术素材

把图片按约定文件名放进 `assets/`，并登记到 `assets/manifest.js`（`serve.ps1` 启动时自动生成），刷新即替换，没放的继续用程序画的：

- `assets/bg/battle.png`（1080×1920）战场背景
- `assets/heroes/<武将id>.png`（512×512 透明底，脚底中心在 256,440）武将立绘；`<武将id>_head.png` 头像可选
- `assets/enemies/<敌人id>.png`（同上）敌人

完整规格和武将 id 对照见 `美术素材规格.md`；模板在 http://localhost:8731/tools/art-guide.html 下载。
技能特效和界面图标目前仍是程序画的。
