# 美术素材规格

画好的图按下面的文件名放进 `assets/`，并登记到 `assets/manifest.js`（用 serve.ps1 启动会自动生成），刷新游戏就会替换程序画的；没放的继续用程序画的，可以一张一张换。

带标注的模板在 `tools/art-guide.html`：先启动本地服务器（`powershell -ExecutionPolicy Bypass -File serve.ps1`），
再打开 http://localhost:8731/tools/art-guide.html ，可以下载背景参考图、武将模板、敌人模板，里面也有完整的文件名清单。

## 总体

- 游戏是竖屏 9:16，逻辑分辨率 540 × 960，素材按 2 倍画（下面的像素都是素材实际像素）。
- 视角：斜俯视。敌人从画面上方往下走，武将站在画面下方的城墙上。
- 光源统一从左上方来，人物不要自带地面阴影（游戏会画阴影和品质光圈）。
- 人物建议 Q 版 2–2.5 头身，轮廓清晰，缩到手机上约 1 厘米高还能认出来。
- 如果是 3D 建模：用同一个固定机位渲染成透明底 PNG（建议正交相机、俯角 30°–45°），所有角色共用机位和灯光。

## 1. 战场背景

| 项 | 规格 |
|---|---|
| 文件 | `assets/bg/battle.png`（或 `battle.jpg`） |
| 尺寸 | 1080 × 1920 |
| 城墙线 | y = 1474：垛口上沿，敌人走到这条线上方停下攻城 |
| 射程线 | y = 350：敌人越过后才会被攻击，线以上画远景和敌军来路 |
| 武将脚底 | (192,1682) (366,1742) (540,1658) (714,1742) (888,1682)，这一片地面保持平整 |
| 界面遮挡 | 顶部 0–190、底部 1780–1920、左上三个圆形按钮，别放重要细节 |
| 两侧 | 左右各约 96 像素敌人不会走到，适合画箭楼、旗帜、拒马 |

## 2. 武将立绘

| 项 | 规格 |
|---|---|
| 文件 | `assets/heroes/<武将id>.png`，例如 `guanyu.png` |
| 尺寸 | 512 × 512，透明底 PNG |
| 锚点 | 脚底中心在 (256, 440)，即横向 50%、纵向 86% |
| 占位 | 身体大致在中间 60% × 80% 的范围内；武器、披风可超出，但别贴边 |
| 朝向 | 所有武将统一一个朝向 |
| 头像（可选） | `assets/heroes/<武将id>_head.png`，正方形（建议 256 × 256）；不提供时自动取立绘上半身 |

游戏里会给立绘加轻微的呼吸和出手动作，不需要画多帧。之后想加攻击帧动画再扩展。

## 3. 敌人

| 文件 | 敌人 | 体型 |
|---|---|---|
| `assets/enemies/grunt.png` | 黄巾兵 | × 1.00 |
| `assets/enemies/shield.png` | 刀盾兵 | × 1.15 |
| `assets/enemies/rider.png` | 轻骑 | × 1.15 |
| `assets/enemies/archer.png` | 弓手 | × 0.92 |
| `assets/enemies/elite.png` | 校尉 | × 1.46 |
| `assets/enemies/boss.png` | 敌将 | × 2.62 |

- 尺寸和锚点同武将：512 × 512，透明底，脚底中心 (256, 440)。
- 每个敌人都按“撑满模板”来画，体型差异由游戏按上表比例放大，不用自己缩放。
- 朝向：面朝画面下方（朝城墙走）。
- 小兵同屏会有几十个，颜色和轮廓要能一眼区分兵种。

## 建议的顺序

1. 背景 1 张：换上后整体观感变化最大。
2. 初始三将（廖化、周仓、裴元绍）和黄巾兵：一进游戏就能看到。
3. 其余敌人 5 种，再按品质从高到低补武将。

## 目前还不能用图片替换的

技能特效（刀气、火球、毒潭、旋风、闪电）、界面按钮和图标仍是程序画的，等立绘风格定下来再接。
